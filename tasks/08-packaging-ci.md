# Task 08: Multi-Platform Packaging & CI/CD

## Objective
Configure build targets, package generators, and automated GitHub Actions workflows for Linux, macOS, and Windows.

## Acceptance Criteria
- [ ] Setup GitHub Actions matrix build for Linux (`ubuntu-latest`), macOS (`macos-latest`), and Windows (`windows-latest`).
- [ ] Configure Linux packages: `.deb`, `.rpm`, `.AppImage`, and Arch Linux `PKGBUILD`.
- [ ] Configure macOS `.dmg` and universal binary build.
- [ ] Configure Windows NSIS / `.msi` packaging.
- [ ] Ensure binaries are stripped, optimized for release, and tagged properly on GitHub releases.
